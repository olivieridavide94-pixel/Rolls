ROLLS V1 - Offline English prototype

How to run on a PC:
1. Open index.html with Microsoft Edge, Google Chrome or Mozilla Firefox.
2. No internet connection is required: all calculations run locally.

Included functions:
- price conversion: currency/kg, currency/m2 and currency/linear metre
- quantity conversion: kg, m2 and linear metres
- linear metres to roll diameter
- roll diameter to linear metres
- 3-inch and 6-inch cores, custom core diameter and core wall thickness
- winding factor
- area, net weight, number of turns and radial build

This is a working offline HTML prototype. It can later be packaged as a native Windows or iPhone application.
