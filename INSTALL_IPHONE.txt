ROLLS iPhone PWA v4.7

This package contains the iPhone version of the latest desktop build, including all calculators, saved calculations, presets, settings, About page, offline storage, test method notes, Roll Build Factor, 3/5/6-inch cores, and the latest Roll Preview.

UPDATE THE EXISTING GITHUB PAGES APP
1. Open the Rolls repository on GitHub.
2. Delete the old published app files, or overwrite files with the same names.
3. Upload the CONTENTS of this package, not the ZIP itself:
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - assets folder
   - icons folder
4. Commit the changes to main.
5. Wait for GitHub Pages deployment to complete.

REFRESH THE INSTALLED IPHONE APP
1. Open the GitHub Pages address in Safari once.
2. If an older version remains, remove the old ROLLS icon from the Home Screen.
3. In Safari, reload the page and then use Share > Add to Home Screen > Open as Web App > Add.
4. Open ROLLS once online, then test with Airplane Mode.

All saved calculations and presets use local browser storage. Removing website data may delete those locally saved records.
